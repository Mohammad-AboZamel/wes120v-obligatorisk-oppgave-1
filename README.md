# WES120V-prosjekt

Dette prosjektet er et minimalt Vite-prosjekt laget som en del av WES120V.

## Forutsetninger

Node.js og pnpm må være installert.

## Installere avhengigheter

Kjør:

pnpm install

## Starte utviklingsserveren

Kjør:

pnpm dev

Åpne siden på adressen Vite viser i terminalen.
